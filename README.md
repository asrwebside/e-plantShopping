# Paradise Nursery Shopping Application

Paradise Nursery is a responsive React e-commerce demo for browsing indoor houseplants and managing a shopping cart.

## Features

- Welcome landing page with a clear **Get Started** action.
- Company information page.
- 18 houseplants across three categories: Air Purifying, Low Maintenance, and Succulents.
- Product cards with thumbnails, descriptions, prices, and Add to Cart controls.
- Redux Toolkit cart state with quantity adjustments, item removal, item counts, and totals.
- Shared navigation across Home, Plants, About Us, and Cart.
- Checkout placeholder message and Continue Shopping navigation.
- Responsive layout for desktop and mobile screens.

## Built with

- React and Vite
- React Router
- Redux Toolkit and React Redux
- CSS
- Lucide React icons

## Run locally

Install Node.js (LTS), then run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in your terminal.

To create a production build:

```bash
npm run build
npm run preview
```

## Main files

- `src/App.jsx` — routes and landing page
- `src/App.css` — global styling and landing page background
- `src/components/AboutUs.jsx` — company information
- `src/components/ProductList.jsx` — plant catalog and add-to-cart buttons
- `src/components/CartItem.jsx` — shopping cart interface
- `src/redux/CartSlice.jsx` — Redux cart state
- `src/redux/store.js` — Redux store

## Notes

Product photos are loaded from Unsplash source URLs and therefore require an internet connection. This is a learning project; checkout is intentionally a placeholder and does not process payments.
